# ASGARD-IRI

ASGARD International Foundation for Research and Innovation website monorepo.

## Structure
- `client/`: React.js SPA (Vite + Tailwind CSS)
- `server/`: Express.js REST API + PostgreSQL
- `uploads/`: Uploaded assets and documents
